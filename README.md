# פיד AI יומי

מייל יומי בעברית עם פריטי AI מעשיים, מעוצב ב-RTL.
רץ דרך **המשימות המתוזמנות של קלוד**. אין שרת, אין n8n, אין RSS,
**ואין מפתח API ואין סיסמת SMTP** - קלוד מחפש בכלי החיפוש שלו
ושולח דרך מחבר ג'ימייל.

## מבנה

```
.claude/skills/ai-feed/SKILL.md    ההוראות: מה לחפש, מה מסננים, איך שולחים
.claude/skills/ai-feed/render.js   רינדור ה-HTML, דטרמיניסטי
task-prompt.txt                    הטקסט להדבקה לתוך המשימה המתוזמנת
```

## התקנה

הריפו הזה הוא **המקור** של הסקיל, לא מקום ההרצה שלו.
סקיל שיושב רק בריפו אינו נראה למשימות מתוזמנות - הוא חייב להיות
**מותקן ברמת החשבון**, כמו כל סקיל אישי אחר.

1. ודא שמחבר **Gmail** מחובר בהגדרות קלוד
2. ארוז את תיקיית הסקיל והתקן אותה כסקיל אישי:
   ```bash
   cd .claude/skills && zip -r ai-feed.zip ai-feed
   ```
   ואז העלה את `ai-feed.zip` במסך הסקילים של קלוד
3. פתח **Scheduled tasks**, צור משימה יומית והדבק לתוכה את הטקסט
   שבקובץ `task-prompt.txt`

לאחר כל שינוי ב-`SKILL.md` או ב-`render.js` צריך לארוז ולהעלות מחדש.

## מניעת חזרות

ההיסטוריה שמורה כ**טיוטה בג'ימייל** בשם `AI-FEED-HISTORY` - כותרת בכל שורה,
300 שורות אחרונות. לכן אין צורך בקובץ, בגיט או באחסון חיצוני.
בכל בוקר 120 הכותרות האחרונות נכנסות לשיקול, עם הוראה לא להביא פריט
דומה מהותית גם בניסוח שונה.

הטיוטה נשארת טיוטה ולעולם לא נשלחת. אם תמחק אותה, הפיד יתחיל היסטוריה מחדש.
אם רוצים "לשכוח" פריט מסוים - פשוט מוחקים את השורה שלו מהטיוטה.

## למה `render.js` ולא רינדור על ידי קלוד

אם קלוד יכתוב את ה-HTML מחדש כל בוקר, העיצוב יזוז מיום ליום - צבע פה,
ריווח שם. הסקריפט מייצר פלט זהה בייט-לבייט מאותו קלט, וקלוד אחראי רק
על התוכן.

## בדיקה ידנית

```bash
node .claude/skills/ai-feed/render.js items.json email.html
open email.html
```

## הערות על העיצוב

המייל בנוי טבלאות HTML מקוננות עם סטיילינג inline, כי Outlook לא תומך
ב-CSS מודרני. רוחב מקסימלי 600px. `dir="rtl"` על ה-html, ה-body והטבלה
הראשית, ובלוק הפרומפט באנגלית מקבל `direction:ltr` ו-`text-align:left`
נפרדים כדי שלא יתהפך.
